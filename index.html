Herencia, una historia para contar

Herencia nace como archivo visual: prendas que se miran, se recuerdan y se cuentan. Este sitio es un catálogo. No hay carrito, pagos ni pedidos. Solo la colección.

Siluetas oversize, denim amplio y gráficos que vienen de símbolos propios. Cada pieza se muestra para verse de cerca: cortes, colores y cómo se lleva.

Explora hombre y mujer. Entra a cada prenda para ver más fotos, la descripción y las tallas disponibles. Si quieres hablar con la marca, usa Instagram o WhatsApp al pie.
